# Beszel

Lightweight host and Docker container monitoring (Hub + Agent) exposed at `https://beszel.<domain>`.

## Architecture

- **beszel** (`henrygd/beszel:latest`): Web UI + PocketBase backend behind Traefik (`internal-chain@file`, Tailscale-only).
- **beszel-agent** (`henrygd/beszel-agent:latest`): Runs in `network_mode: host`, mounts `/var/run/docker.sock:ro`, and communicates with the Hub over a shared Unix socket (`beszel-socket:/beszel_socket`).

## Secrets (`config/secrets.enc.yml`)

- `beszel_admin_email` / `beszel_admin_password`: Admin login credentials.
- `beszel_agent_key`: SSH public key generated by Beszel Hub for authenticating `beszel-agent`.
- `discord_webhook_url`: Synced automatically on deploy via `scripts/sync-monitoring-webhooks.py` (converted to Shoutrrr `discord://<token>@<id>` format).
